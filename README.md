# Awesome cvc5

Move between an SMT-LIB problem and an API example while keeping the logic and expected result visible.

- [Project and community](https://cvc5.github.io/) — Find release information, research and the project discussion channel.
- [Manual](https://cvc5.github.io/docs/latest/) — Choose the manual corresponding to the installed release before using solver options.
- [Worked examples](https://cvc5.github.io/docs/latest/examples/examples.html) — Compare the examples in the available APIs and SMT-LIB.
- [Source and issues](https://github.com/cvc5/cvc5) — Inspect regression inputs or report a minimal reproducer with the solver version.

## A first exercise

Take the quickstart example in the manual. Change one assertion to contradict a previous assertion and compare the solver responses.
